# Reference

The reference section is the fleet's measurement plate: exact, generated-from-source pages where
prose cannot drift from the code. When you need a version, a channel rule, a component's body
layer, or a model's context window, this is where the numbers live.

- [Manifest — components.toml](manifest.md): every organ of the Agentic Body declared in one
  auditable file.
- [Channels — stable/canary/devel](channels.md): the release filters and the gates a change must
  clear to rise.
- [Components — all shesh-*](components/README.md): the manifest projected into a table you can
  scan.
- [Models — models.toml](models.md): capabilities, context size, cost, and free tier for each
  model.
- [Upstreams — Sources & Steal-Map](upstreams.md): what the fleet tracks upstream and why.

These pages are generated or generated-adjacent. Treat the manifest and models files as the source
of truth; the prose around them explains how to read the data, never the data itself.
